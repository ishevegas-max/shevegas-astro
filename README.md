# SheVegas Astro

The canonical visual-first Astro publication for `shevegas.com`.

Current operating truth and handoff instructions live in [`HANDOFF.md`](HANDOFF.md). Old Next.js, static-packaging and democracy-prototype instructions are superseded.

## Rules

- Michael Brunette / SheVegas-owned artwork only.
- No stock or generated filler.
- One dominant artwork assignment per story; reuse only when editorially necessary.
- Static Astro output. JavaScript is limited to the seamless story browser.
- The publication loads once; story URLs remain shareable and browser navigation remains intact.

## Commands

```sh
npm install
npm run build
npm run dev
```
